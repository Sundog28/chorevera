## Chorevera

Production household-management SaaS built with **React, TypeScript, FastAPI, PostgreSQL, Stripe, and OpenAI**.

Highlights include multi-user households, secure JWT authentication, subscription billing/webhooks, transactional email, notifications, analytics, automated workload balancing, database migrations/backups, security hardening, and an AI Household Planner with structured output, deterministic validation, and human approval before database changes.

**Live:** https://choreflow-web.onrender.com  
**Repo:** https://github.com/Sundog28/choreflow
